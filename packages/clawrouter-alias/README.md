# clawrouter

This name is held by BlockRun. It is an alias for the official package,
[`@blockrun/clawrouter`](https://www.npmjs.com/package/@blockrun/clawrouter):
`npx clawrouter` and `npm install -g clawrouter` run the same CLI.

Prefer the scoped name in new instructions:

```sh
npx @blockrun/clawrouter
```
